# T-A through T-H 80-case experiment — Not Run

The real O-C versus O-D construction ablation was executed with constrained live
semantic calls. It was file-based and did not create independently published
reviewed O-C, reviewed O-D, and Gold ontology versions.

The 640-case T-A through T-H experiment was therefore **not run**. Running it
without distinct ontology version IDs, bundle/artifact hashes, and version-bound
SQLAsset builds would violate the experiment isolation rules. No mock,
historical, or four-group benchmark result was relabeled as V2 evidence.
